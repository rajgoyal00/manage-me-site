Manage Me

Access Control Policy

Effective 2026-09-28 · Last reviewed 2026-09-28

Accounts and roles

Manage Me has a single owner/admin account. There are no other users, no roles and no shared accounts. The owner is also the only person with access to the Mac it runs on, GitHub, the Plaid Dashboard, Gmail, and OpenAI. There is no single sign-on (SSO) or identity provider; each account is managed directly.

Least privilege

  • The app asks Plaid only for the data it uses (transactions, and card and loan details when the user agrees). It never asks for the ability to move money.
  • API keys and bank access tokens exist only on the owner's computer. They are never shared or copied anywhere else.
  • Anyone who is ever given access gets only what their task needs, only for as long as they need it.

Multi-factor authentication

MFA is required. The app asks for a password and an authenticator code at every sign-in. MFA is also required on every account that can reach the data or keys: the Plaid Dashboard, OpenAI, GitHub, and Gmail.

Quarterly access review

Every quarter, the owner reviews who has access to the Mac, GitHub, the Plaid Dashboard, Gmail and OpenAI. Anything that isn't needed is removed, MFA is confirmed on each account, and the review date is recorded.

Revoking access

If a device is lost or stolen, or a collaborator ever leaves, the owner will immediately revoke credentials and rotate keys:

  • Remove that person's or device's access to every account above.
  • Rotate the Plaid secret and the OpenAI key.
  • Rotate the app's encryption key and session signing key, which ends every session, and reset the app's two-step sign-in.
  • If the lost device held the database, revoke all Plaid connections from the Plaid Dashboard.
