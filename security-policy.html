Manage Me

Information Security Policy

Effective 2026-09-28 · Last reviewed 2026-09-28

Scope

Manage Me is personal software built and run by a single developer, who is also its only user. It runs only on the owner's own computer and is not a hosted service. This policy covers that computer, the app, and the accounts used to run it (Plaid Dashboard, OpenAI, GitHub, and email).

Encryption at rest

  • The computer's disk is fully encrypted (macOS FileVault). This protects the whole database, including transactions and balances.
  • Inside the database, the most sensitive values are encrypted again: Plaid access tokens, Plaid and OpenAI API keys, the two-step sign-in secret, and tax ID numbers. This uses Fernet (AES-128 in CBC mode with an HMAC-SHA256 check).
  • The encryption key is kept in a separate file that only the owner's user account can read. It is never put in source control.

Encryption in transit

  • Every call to Plaid and to OpenAI uses HTTPS (TLS) with certificate verification turned on.
  • The app only listens on the computer itself (127.0.0.1), so it can't be reached from the network.

Sign-in and multi-factor authentication

  • Signing in to the app needs a password and a code from an authenticator app (TOTP). This is required, not optional.
  • Passwords are stored only as bcrypt hashes. One-time backup codes are stored only as hashes.
  • After 5 wrong codes, code entry is locked for 15 minutes. Sessions end after 7 days.

Vulnerability scanning and patching

Python and JavaScript dependencies are checked for known vulnerabilities with pip-audit and npm audit at least weekly, and before any update is deployed. Security fixes are applied within these times, counted from when a fix is available:

SeverityFixed within
Critical7 days
High30 days
Medium and low90 days

If no fix exists, the affected component is replaced or the risk is reduced in some other way within the same time.

End-of-life software

Every quarter, the owner checks the versions of the operating system, Python, Node.js and the main frameworks against their published end-of-life dates, and upgrades before any of them reaches end of life.
